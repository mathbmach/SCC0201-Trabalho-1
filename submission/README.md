# Arquivos preparados para envio

## Run.Codes — programa principal

Preferencialmente, envie os três arquivos de `src/`:

- `src/main.c`
- `src/algoritmos.c`
- `src/algoritmos.h`

Se a plataforma aceitar **apenas um arquivo** `.c`, use `programa_unico.c` desta pasta. Ele é a junção dos três arquivos acima, sem nenhuma alteração de lógica, e foi verificado como produzindo saída idêntica à versão em três arquivos.

## e-disciplinas — relatório e códigos auxiliares

- `report/relatorio.pdf`
- os quatro arquivos de `experiments/`
- opcionalmente, os CSVs de `data/` e o script `graphs/gerar_graficos.py`

- [ ] Nomes e números USP no cabeçalho do código e na capa do relatório.
- [ ] Tabela de contribuições preenchida.

- [ ] Exemplo do enunciado conferido.
